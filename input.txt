@c buddy slots. In practice, it is likely that more than one block of memory
will be used for allocating small segments of memory, and therefore more
than one instance of a buddy allocator will be required.
A single block of memory can be used to house the metadata of multiple
instances of a buddy allocator. One instance takes up 10 words of space
without any padding (AVAIL is 7 words, TAGS is 2 words, the address of BLOCK is 1 word).
A maximum of 6 instances can fit on a block.
Each memory region associated with a potential instance will be referred
to as a "slot". 4 words are a left over. These will be used to construct
a TOP struct that can be passed into calls to the buddy memory allocator.
A slot is selected, and then the addresses of AVAIL, BLOCK, and TAGS will
be set in the TOP struct before the buddy memory allocator is called.
